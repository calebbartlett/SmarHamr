artifact_logic_engine
===========================================
HYBRID TRISKELE + SYMBIOTIC NODE ENGINE
===========================================

OVERVIEW:
The hybrid engine consists of two layers:

1. TRISKELE (Internal Nervous System)
2. SYMBIOTIC NODE ENGINE (External Influence Network)

Together they create a dynamic, emergent simulation system.

-------------------------------------------
1. TRISKELE ENGINE (INTERNAL LOGIC)
-------------------------------------------

Each asset (character, vehicle, environment, group, system, scene) has three spirals:

HAND:
- Action vector
- Manipulation, intervention, agency
- “What the asset DOES”

HEARTH:
- Stability vector
- Safety, cohesion, grounding
- “What keeps the asset CENTERED”

SHADOW:
- Pressure vector
- Distortion, threat, entropy
- “What pushes the asset OFF BALANCE”

These spirals define the asset’s INTERNAL behavioral signature.

Triskele = “This is who the asset IS.”

-------------------------------------------
2. SYMBIOTIC NODE ENGINE (EXTERNAL LOGIC)
-------------------------------------------

Assets form TETHERS to other assets.

A tether means:
“Asset A is currently connected to Asset B.”

Through tethers, traits FLOW between assets.

Examples:
- A character tethered to a dark environment absorbs Shadow.
- A vehicle tethered to a skilled pilot absorbs Hearth.
- A scene tethered to a chaotic crowd absorbs Hand.

Node Engine = “This is who the asset BECOMES in this moment.”

-------------------------------------------
3. TRAIT FLOW MECHANISM
-------------------------------------------

When tethered:
- External spirals influence internal spirals.
- Influence strength depends on tether intensity.
- Influence persists until tether breaks.

Example:
Character enters a Shadow-heavy shaft:
Character.Shadow += Shaft.Shadow
Character.Hearth -= Shaft.Shadow
Character.Hand -= Shaft.Shadow

This creates dynamic state changes.

-------------------------------------------
4. THEMATIC COLLAPSE (RISK)
-------------------------------------------

If external influence overwhelms internal spirals:
- The asset loses its identity.
- The environment overwrites the character.
- The character becomes a manifestation of the environment.

This is called:
THEMATIC COLLAPSE

-------------------------------------------
5. TETHER OF ORIGIN (ANCHOR)
-------------------------------------------

To prevent collapse, each asset must have a CORE ANCHOR:

TetherOfOrigin:
- A persistent identity vector
- Resists external influence
- Maintains psychological elasticity
- Allows recovery after intense tethering

Without it:
- The system becomes a transformation engine
With it:
- The system remains an interaction engine

-------------------------------------------
6. HYBRID ENGINE SUMMARY
-------------------------------------------

TRISKELE:
Internal nervous system
Defines identity
Stable, token-efficient

NODE ENGINE:
External circulatory system
Defines influence
Dynamic, emergent

HYBRID:
Identity + Influence = Behavior
Stable + Dynamic = Simulation

-------------------------------------------
7. WHY THIS ENGINE WORKS
-------------------------------------------

- Token-efficient
- No personality sheets
- Assets behave like systems
- Environments behave like characters
- Characters evolve naturally
- Scenes exert pressure
- Behavior is emergent, not scripted
- Perfect for Perchance and SmarHamr

-------------------------------------------
8. USER WORKLOAD & MAINTENANCE
-------------------------------------------

The user maintains ONLY three elements:

1. TRISKELE SPIRALS (per asset)
   - Hand (action)
   - Hearth (stability)
   - Shadow (pressure)
   Expressed as:
     - short phrases
     - numeric vectors
     - thematic tags

2. CORE RESONANCE (identity anchor)
   - A single concept defining the asset’s baseline identity
   - Prevents thematic collapse
   - Supports recovery after influence

3. TETHERS (connections between assets)
   - Declared simply as:
       AssetA ↔ AssetB
   - Engine handles influence flow automatically
   - Update only when scene changes

Everything else is AUTOMATIC:
- influence propagation
- state changes
- environmental pressure
- emergent behavior
- narrative cohesion
- collapse prevention
- elasticity recovery
- scene modulation
- dynamic arcs
- continuity
- influence decay
- return to baseline

Typical workload:
- 5 assets → 5 Triskele sets
- 5 core resonances
- 3–6 tethers
Total user effort: 5–10 short lines of data.

-------------------------------------------
9. STATE ELASTICITY (STABILIZER)
-------------------------------------------

State Elasticity ensures that an asset’s identity does not permanently distort under external influence. Each spiral (Hand, Hearth, Shadow) has a baseline identity value and an elasticity coefficient that determines how strongly it returns to that baseline after being pushed by external pressure. This creates temporary transformations rather than permanent overwrites, allowing assets to recover naturally once tethers weaken or break. Elasticity is the primary safeguard against long-term behavioral drift.

-------------------------------------------
10. SCENE PRESSURE MODULATION (ENVIRONMENTAL CONTROL)
-------------------------------------------

Scenes exert influence through pressure curves that determine how strongly their spirals affect tethered assets. Pressure exists in three levels: Soft (ambient), Medium (active), and Hard (overwhelming). These levels shift based on proximity, duration, and narrative intensity. Scene Pressure Modulation prevents abrupt or unrealistic changes by allowing environmental influence to rise or fall smoothly, creating natural tension and pacing within the simulation.

-------------------------------------------
11. INTERACTION MEMORY (SHORT-TERM CONTINUITY)
-------------------------------------------

Interaction Memory stores short-term traces of recent tether activity, including the last tether, last influence, and last spiral shift. These traces decay over time but provide continuity between scenes, preventing characters from resetting abruptly. Interaction Memory creates behavioral inertia, allowing actions, emotions, and environmental effects to carry forward in a controlled, natural way. This produces emergent arcs without requiring manual tracking.

-------------------------------------------
12. DUAL-ORIGIN ANCHORING (ADVANCED COLLAPSE PREVENTION)
-------------------------------------------

Dual-Origin Anchoring gives each asset two stabilizing anchors: Identity Origin (who the asset IS) and Purpose Origin (what the asset SEEKS or DOES). If external influence overwhelms identity, purpose can still pull the asset back from collapse. This two-anchor system provides the strongest protection against thematic collapse, ensuring that even under extreme pressure, assets retain coherence, agency, and psychological elasticity. Dual-Origin Anchoring maintains narrative integrity while allowing deep, transformative interactions.
